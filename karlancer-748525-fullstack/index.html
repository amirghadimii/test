داده‌های دمو

همه تغییرات این دمو (سفارش‌ها، مشتریان و تنظیمات) در حافظه مرورگر شما ذخیره می‌شود و با بارگذاری مجدد باقی می‌ماند. برای شروع دوباره می‌توانید داده‌ها را به حالت نمونه اولیه برگردانید.

درباره این دمو — نقشه راه نسخه نهایی

این صفحه یک دموی زنده و کاملاً تعاملی است: ورود، داشبورد تحلیلی، مدیریت کامل سفارش‌ها و مشتریان و تنظیمات — همه همین‌جا در مرورگر کار می‌کنند تا دقیقاً حس محصول نهایی را ببینید. در نسخه نهایی، همین رابط کاربری با معماری فول‌استک زیر به سرور واقعی متصل می‌شود؛ بدون تغییر در تجربه کاربری.

فرانت‌اند: React

همین صفحات به کامپوننت‌های React تبدیل می‌شوند؛ مدیریت state، روتینگ سمت کاربر و فرم‌های کنترل‌شده با اعتبارسنجی — دقیقاً همان تعامل‌هایی که در دمو می‌بینید.

بک‌اند: Node.js + Express

سرور API با Express؛ لایه‌های route / controller / service، میدلورهای احراز هویت و لاگ، و مدیریت خطای یکپارچه برای همه endpointها.

دیتابیس: PostgreSQL

جداول نرمال‌شده مشتریان، سفارش‌ها و کاربران با کلید خارجی، ایندکس روی فیلدهای جستجو و تراکنش برای عملیات حساس مالی.

احراز هویت: JWT

ورود با توکن JWT و Refresh Token، هش رمز عبور با bcrypt و سطوح دسترسی نقش‌محور (مدیر / کارشناس فروش) روی تک‌تک endpointها.
